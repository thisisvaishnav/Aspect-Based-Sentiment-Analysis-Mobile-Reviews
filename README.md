# Aspect-Based Sentiment Analysis on Mobile Phone Reviews

## 📖 Project Overview
This project implements an Aspect-Based Opinion Mining system for analyzing mobile phone reviews. The system extracts key product aspects such as battery, camera, price, display, and performance, and determines the sentiment polarity (Positive/Negative) associated with each aspect.

## 🎯 Problem Statement
Traditional sentiment analysis provides overall sentiment of a review. This project focuses on identifying sentiment related to specific product features.

## 📊 Dataset
The dataset used in this project is the ZMEZONE Mobile Reviews dataset obtained from Kaggle. It contains customer reviews of various mobile phones.

## 🛠 Technologies Used
- Python
- Pandas
- NLTK
- TextBlob
- Matplotlib

## ⚙️ Methodology
1. Data preprocessing (tokenization, stopword removal)
2. Aspect identification (predefined mobile features)
3. Sentiment analysis using lexicon-based approach
4. Aspect-wise sentiment classification

## 📈 Output
The system provides:
- Aspect-wise sentiment classification
- Sentiment distribution visualization
